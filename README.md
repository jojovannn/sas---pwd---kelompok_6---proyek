# Gloss Barbershop

Selamat datang di **Gloss Barbershop**, website ini dirancang untuk memberikan informasi lengkap mengenai layanan pemotongan rambut dan styling rambut *Hanya Untuk* pria eksklusif dengan standar pelayanan bintang lima.

### Lembar Konsep Usaha: Gloss Barbershop
- **Jenis Usaha**: Jasa potong rambut dan styling rambut pria (*Barbershop*).
- **Ciri Khas**: Tempatnya bersih dan nyaman ala *lounge*, melayani pemotongan presisi modern, serta ada layanan khas *classic hot towel shave* (cukur dengan handuk hangat) berstandar bintang 5.
- **Lokasi & Tahun Berdiri**: Jl. Gajah Mada No. 8, Pontianak Kota (Berdiri tahun 2015).
- **Pendiri**: Marco Gloss JR & Tim Kelompok (Kelas X TKJ 1).
- **Target Pelanggan**: Teman-teman pelajar/siswa, mahasiswa, sampai mas-mas pekerja muda yang ingin selalu tampil rapi dan percaya diri.
- **3 Warna Utama & Alasan Memilihnya**:
  - **Hitam (`#000000`)**: Dipilih biar tampilan website kelihatan tenang, elegan, dan maskulin.
  - **Emas (`#D4AF37`)**: Dipilih buat melambangkan kualitas pelayanan kelas atas (bintang 5).
  - **Putih (`#FFFFFF`)**: Dipilih sebagai warna dasar biar websitenya kelihatan bersih dan tulisan mudah dibaca oleh pengunjung.
